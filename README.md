# Awesome DeepSeek CLI

*Unofficial community list for DeepSeek CLI (Deep Code). Not affiliated with DeepSeek. All trademarks belong to their owners.*

A curated list of links for anyone setting up a deepseek cli workflow with Deep Code, the open-source terminal coding assistant for DeepSeek-V4 that the DeepSeek API docs document as an agent integration. Every entry is a page the DeepSeek docs or site actually link to; the list is deliberately short rather than padded with guessed URLs.

> Need a finished site or app rather than a coding agent? [Try Begin.sh - turn a prompt or a URL into a static site or Expo app and download the zip](https://begin.sh?utm_source=github&utm_medium=ugc&utm_campaign=awesome-deepseek-cli&utm_content=readme-top&utm_term=tier-r).

## Official resources

- [Integrate with Deep Code](https://api-docs.deepseek.com/quick_start/agent_integrations/deepcode/) - the integration page: install, `settings.json`, shortcuts, skills.
- [Deep Code CLI on GitHub](https://github.com/lessweb/deepcode-cli) - source for the terminal assistant.
- [Deep Code VS Code extension on GitHub](https://github.com/lessweb/deepcode) - shares the same settings file as the CLI.
- [DeepSeek API docs](https://api-docs.deepseek.com/) - docs home.
- [Copilot CLI integration](https://api-docs.deepseek.com/quick_start/agent_integrations/copilot_cli) - the sibling integration page (was not fetchable at crawl time).
- [Deep Code docs in Chinese](https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/deepcode) - same page, zh-CN.

## Getting started

- [DeepSeek Platform](https://platform.deepseek.com/) - account and billing.
- [API keys](https://platform.deepseek.com/api_keys) - create the key that goes in `settings.json`.
- [Node.js downloads](https://nodejs.org/en/download/) - Deep Code needs Node 18 or newer.
- [API pricing](https://api-docs.deepseek.com/quick_start/pricing) - per-token rates for the models you set in `MODEL`.
- [Service status](https://status.deepseek.com/) - check here before blaming your config.
